# dyn-standards

Shared Dyn engineering standards, packaged so the team can consume them through
Kiro. Each subfolder is a self-contained set of Kiro skills for one topic.

## Contents

| Folder | What it covers |
|--------|----------------|
| [`tagging-kiro-skills/`](tagging-kiro-skills/) | AWS resource tagging standard, how-to, governance, and contacts |

More standards can be added as sibling folders over time (e.g. backup,
onboarding, security), each following the same layout:
`<topic>-kiro-skills/.kiro/skills/<skill-name>/SKILL.md`.

## Using the skills

Kiro skills are **pull, not push** - they teach Kiro to answer well when you
ask; they do not notify anyone. See each folder's README for the two ways to
activate its skills (open the folder in Kiro, or copy the skill into
`~/.kiro/skills/` to have it active in every repo).
